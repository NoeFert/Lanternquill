# Instructions pour Claude

## Périmètre
- Fais uniquement les tâches demandées, n'ajoute rien de ta propre initiative.
- N'importe rien sans me demander (aucune nouvelle dépendance, librairie ou module).
- Ne fais aucun commit : je suis la seule à les faire. Tu peux me conseiller quand un commit te semble opportun.

## Code
- Code minimal, le plus basique et dry possible.
- Respecte la structure et l'organisation existantes du code. Si un changement de structure te semble nécessaire, pose-moi la question avant.
- Commentaires réduits au minimum.
- Utilise les composants Ionic (`IonButton`, `IonList`, `IonItem`…) plutôt que du HTML brut quand un équivalent existe.
- Pour les icônes présentes dans mes maquettes ou wireframes, utilise les icônes Ionic (`ionicons`).
- Vérifie que le code proposé correspond aux versions des librairies utilisées par l'app (voir `package.json`).

## Style
- Nous sommes en phase 1 : on reste sur un wireframe, le CSS est gardé au minimum.

## Langue
- Le code est écrit entièrement en anglais (noms de variables, fonctions, fichiers, etc.).
- Les commentaires, tes réponses, le contenu texte et les labels de l'interface sont en français.

## Questions
- Quand tu as plusieurs questions, pose-les une par une.
- Si une de mes demandes contredit ces instructions, préviens-moi et demande-moi comment procéder avant d'agir.

## Apprentissage
- Si j'indique dans ma demande que je n'ai jamais utilisé un langage ou un élément de code, explique brièvement les notions nouvelles introduites. Je dois être capable de recoder la même chose seule ensuite.
